# 输入数据与限额配置说明

## 报销记录 CSV 格式

编码 UTF-8（带或不带 BOM 均可），首行为表头，必需列：date、employee、category、amount、currency、note。

样例：

```csv
date,employee,category,amount,currency,note
2026-09-02,张三,travel,1200.50,CNY,北京出差高铁票
2026-09-03,张三,meal,86.00,CNY,出差工作餐
2026-09-03,李四,office,199.99,CNY,打印机硒鼓
2026-09-03,李四,other,0.00,CNY,无效金额示例
```

说明：

- amount 必须是两位小数的金额字符串；
- date 必须是 YYYY-MM-DD；
- 表头顺序固定，多余列忽略；
- 坏行（列数不符、字段缺失）不算程序错误，按 REQ-001 进入解析错误清单。

## 限额配置文件格式

JSON 对象，键为类别，值为每月上限（元，数字）：

```json
{
  "travel": 6000,
  "meal": 1500,
  "office": 800
}
```

- 配置中未出现的类别（含 other）不做限额校验，报表注明未设限；
- 限额按「员工×类别×月份」独立计算，跨月不累计。
