

# 需求规格说明书

**项目名称**：expense_reporter（报销单校验与汇总工具）  
**版本**：1.0  
**状态**：草案  

---

## 一、项目概述

### 1.1 项目背景

行政部每月人工核对员工报销 CSV 效率低、易出错。本项目旨在交付一套自动化 CLI 工具，完成报销记录的校验、去重、限额比对与汇总报表输出，降低人工核对成本并提高准确性。

### 1.2 目标用户

| 角色 | 用途 |
|------|------|
| 行政专员 | 批量导入 CSV、查看异常清单与汇总报表 |
| 财务复核人员 | 依据报表与异常清单进行人工复核 |

### 1.3 交付物位置

```
workspace/expense-reporter/
├── expense_reporter/     # 源码包
├── tests/               # 自动化测试
└── README.md            # 使用文档
```

### 1.4 技术约束

- 纯 Python 标准库，不引入任何第三方依赖
- 金额一律使用 `Decimal`，禁止 `float` 聚合

### 1.5 范围外事项

| 排除项 | 说明 |
|--------|------|
| 图形界面 | 仅提供命令行工具 |
| 多币种 | 仅支持 CNY |
| Excel 输入 | 仅支持 CSV 格式 |
| 与报销系统集成 | 无外部系统对接 |
| 数据库持久化 | 无数据存储 |

## 二、功能需求清单

### 2.1 REQ-001（必须）CSV 读取与解析

**描述**：读取 UTF-8 编码（带或不带 BOM）的报销记录 CSV，首行为表头。必需列依次为 `date、employee、category、amount、currency、note`。缺少必需列或某行字段数不符时，把该行记入解析错误清单（含行号与原因），不中断其余行处理；多余列忽略。

**优先级**：必须

**实现状态**：已完成（TASK-002）

---

### 2.2 REQ-002（必须）单条记录校验规则

**描述**：每条有效解析的记录依次校验：
1. `amount > 0`
2. `date` 不晚于当天且不早于 `--max-age-days` 参数指定天数之前（默认 365）
3. `category` 属于允许集合 `{travel, meal, office, other}`
4. `note` 去空白后非空
5. `currency == CNY`

任何一条不满足即记入异常清单，注明行号、违反规则与原始字段值；同一条记录命中多条规则时逐条列出。

**优先级**：必须

**实现状态**：已完成（TASK-003）

---

### 2.3 REQ-003（必须）重复报销检测

**描述**：同一员工 + 同一类别 + 同一金额 + 同一日期的记录视为重复；同一批次内第二次及之后出现的行标记为「重复」，第一次出现保留为有效。重复检测在校验之后进行，仅针对未被判定为异常的记录。检测范围仅限同一次导入批次内部，不与历史文件比对。

**优先级**：必须

**实现状态**：Blocked

---

### 2.4 REQ-004（必须）类别月度限额校验

**描述**：限额配置来自 JSON 文件，键为类别名，值为该类别每月金额上限（元）。按「员工 × 类别 × 月份」聚合有效记录金额，超出上限的记录按时间顺序标记为「超限」，直至该员工该类别当月剩余额度用尽；未提供 `--config` 或配置中缺少某类别时，该部分不做限额校验，并在报告中注明「未设限」。

**优先级**：必须

**实现状态**：Blocked

---

### 2.5 REQ-005（必须）Markdown 汇总报表

**描述**：输出人类可读 Markdown 报表，包含：
1. 报表头（统计口径说明、生成时间、输入文件名、总行数）
2. 三个汇总维度（按员工、按类别、按月份）的有效金额合计与笔数
3. 明细附录：解析错误清单、异常清单、重复清单、超限清单（均含行号）
4. 金额一律为两位小数；无任何清单时显示「无」

**优先级**：必须

**实现状态**：Blocked

---

### 2.6 REQ-006（应该）JSON 机器可读输出

**描述**：`--json` 参数指定输出路径时写出 JSON 文件，含五个键：`summary`（三维合计）、`anomalies`、`duplicates`、`over_limit`、`parse_errors`。所有金额以字符串表示（两位小数），禁止以浮点数表示。

**优先级**：应该

**实现状态**：Blocked

---

### 2.7 REQ-007（必须）命令行接口

**描述**：调用形式为：

```bash
python -m expense_reporter input.csv --config limits.json --report report.md --json report.json --max-age-days 365
```

`--config`、`--json`、`--max-age-days` 均可省略。退出码契约：

| 退出码 | 含义 |
|--------|------|
| `0` | 正常完成且无任何异常记录（解析错误、异常、重复、超限均为空） |
| `1` | 完成处理但存在解析错误、异常、重复或超限记录 |
| `2` | 输入错误（输入文件不存在、必需列缺失、参数非法） |

**优先级**：必须

**实现状态**：Blocked
