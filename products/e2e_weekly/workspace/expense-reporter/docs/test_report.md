## 一、测试概述

### 1.1 测试目标

验证 expense_reporter CLI 工具满足需求规格说明中定义的功能需求与非功能需求，重点覆盖：

- CSV 读取与解析正确性（REQ-001）
- 单条记录校验规则完整性（REQ-002）
- 重复报销检测逻辑（REQ-003）
- 类别月度限额校验（REQ-004）
- Markdown/JSON 报表输出（REQ-005、REQ-006）
- 命令行接口与退出码契约（REQ-007）
- 性能指标（REQ-008）
- 自动化测试覆盖率（REQ-009）

### 1.2 测试策略

| 策略项 | 说明 |
|---|---|
| 测试类型 | 单元测试（pytest） |
| 运行方式 | 全离线，不依赖外部网络或服务 |
| 语言约束 | 纯 Python 标准库，无第三方依赖 |
| 金额精度 | 使用 `decimal.Decimal`，禁止 float 累加 |
| 覆盖范围 | 边界值、异常输入、混合场景、退出码契约 |

### 1.3 测试环境

| 环境项 | 配置 |
|---|---|
| 运行环境 | Python 解释器（标准库） |
| 测试框架 | pytest |
| 工作目录 | `workspace/expense-reporter/` |
| 网络依赖 | 无（全离线） |

#### [TASK-003] 单条记录校验模块

**测试文件**：`tests/test_validator.py`

```bash
cd expense-reporter
python -m pytest tests/test_validator.py -v
python -m pytest tests/ -v
```

**测试结果**：
```
27 passed, 4 subtests passed
```
（含 18 个 validator 测试用例 + 9 个 parser 测试用例）

**覆盖场景**：
- amount > 0 校验（含 0 与负数边界）
- date 时间窗口校验（含超龄与未来日期）
- category 允许集合校验（含非法类别值）
- note 非空校验（含空白字符）
- currency == CNY 校验
- 同一条记录命中多条规则时逐条列出
- validate_rows 批量校验

**对应需求**：REQ-002（单条记录校验规则）
