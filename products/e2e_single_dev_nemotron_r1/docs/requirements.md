# stringkit 需求规格说明书

---

## 1. 项目概述

| 项目属性 | 内容 |
|----------|------|
| **项目名称** | stringkit |
| **项目类型** | Python 纯函数工具包 |
| **核心目标** | 提供三个字符串处理纯函数（反转、回文判断、元音统计），附带单元测试与简要用法说明，供开发者直接导入复用 |
| **交付物** | `stringkit/` 包（含 `__init__.py` 导出三个函数）、`tests/` 单元测试套件、`README.md` 简要用法说明 |
| **版本** | 0.1.0（语义化版本，来源：A-005） |
| **项目布局** | `src/` 布局：`src/stringkit/__init__.py`（来源：A-004） |

---

## 2. 目标用户

- **主要用户**：Python 开发者，需在项目中快速复用字符串反转、回文判断、元音统计功能
- **次要用户**：教学/学习场景下的初学者，参考纯函数实现与测试编写规范

---

## 3. 功能需求清单

| 编号 | 功能名称 | 详细说明 | 优先级 | 来源/备注 |
|------|----------|----------|--------|-----------|
| **REQ-001** | `reverse(s)` | 接收字符串 `s`，返回其字符顺序完全反转的新字符串。空字符串返回空字符串。单字符返回自身。 | 必须 | 需求草案 |
| **REQ-002** | `is_palindrome(s)` | 接收字符串 `s`，**忽略大小写与所有空白字符**（空格、制表、换行等，按 `str.isspace()` 定义，来源：A-002）后，判断是否为回文。返回 `bool`。 | 必须 | 需求草案<br>⚠️ 实现报告 TASK-002 记录为“区分大小写”，与需求草案不一致，需确认 |
| **REQ-003** | `count_vowels(s)` | 接收字符串 `s`，统计其中元音字母（a, e, i, o, u，**不区分大小写**，仅 ASCII，不含带变音符号字母，来源：A-003）出现的总次数，返回 `int`。 | 必须 | 需求草案 |
| **REQ-004** | 单元测试套件 | 使用 `pytest` 覆盖三个函数的正常、边界、异常输入场景，测试通过率 100%，覆盖率 ≥ 90%（`pytest --cov=stringkit`）。 | 必须 | 需求草案 |
| **REQ-005** | 简要用法说明 | `README.md` 包含安装方式、三个函数的签名、典型调用示例、运行测试命令。 | 必须 | 需求草案 |

## 4. 非功能需求

| 维度 | 需求描述 | 来源 |
|------|----------|------|
| **可用性** | 函数签名符合 PEP 8，类型注解完整，docstring 采用 Google 风格。 | 【假设】 |
| **兼容性** | 支持 Python 3.9+；无第三方运行时依赖（测试依赖 `pytest` 仅出现在 `dev` extra）。 | 【假设】 |
| **性能** | 单次调用时间复杂度 O(n)，n 为输入字符串长度；内存占用 O(1) 额外空间（不计输出）。 | 【假设】 |
| **可维护性** | 代码通过 `ruff` / `black` 格式化，`mypy --strict` 无报错。 | 【假设】 |
| **打包发布** | 采用 `pyproject.toml`（PEP 621），支持 `pip install -e .` 与 `pipx run`。 | 【假设】 |

## 5. 验收标准

| 关联需求 | 验收标准（通过/不通过判据） | 实现证据（TASK-002） |
|----------|-----------------------------|----------------------|
| **REQ-001** | `reverse("hello") == "olleh"`；`reverse("") == ""`；`reverse("a") == "a"`。 | 17 个测试用例全部通过，含边界情况 |
| **REQ-002** | `is_palindrome("A man a plan a canal Panama") is True`；`is_palindrome("racecar") is True`；`is_palindrome("hello") is False`；`is_palindrome("") is True`。 | 测试通过，但实现报告注明“区分大小写”，需对齐需求草案的“忽略大小写” |
| **REQ-003** | `count_vowels("hello") == 2`；`count_vowels("PYTHON") == 0`；`count_vowels("aeiouAEIOU") == 10`；`count_vowels("") == 0`。 | 测试通过，实现为不区分大小写，符合预期 |
| **REQ-004** | `pytest -q` 退出码为 0，覆盖率 ≥ 90%（`pytest --cov=stringkit`）。 | `17 passed in 0.03s`，退出码 0；覆盖率待补充测量 |
| **REQ-005** | `README.md` 存在且包含：安装命令、三个函数签名、至少各 1 个调用示例、运行测试命令。 | 已编写，含安装说明、使用示例、API 文档、测试命令 |

## 6. 假设与约束（原样保留并标注来源）

| 编号 | 内容 | 类型 | 来源 |
|------|------|------|------|
| **A-001** | 函数为纯函数：无副作用、无 I/O、无全局状态依赖。 | 约束 | 需求草案 |
| **A-002** | `is_palindrome` 的“空白字符”按 `str.isspace()` 定义（含空格、制表、换行等）。 | 假设 | 需求草案 |
| **A-003** | `count_vowels` 仅统计 ASCII 元音 a/e/i/o/u，不含带变音符号字母（如 á, ö）。 | 假设 | 需求草案 |
| **A-004** | 项目采用 `src/` 布局：`src/stringkit/__init__.py`。 | 假设 | 需求草案 |
| **A-005** | 版本号遵循语义化版本，初始版本 `0.1.0`。 | 假设 | 需求草案 |
