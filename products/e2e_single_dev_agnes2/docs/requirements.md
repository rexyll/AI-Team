

# 需求规格说明书

## 一、项目概述

### 1.1 项目背景

本项目旨在开发一个名为 `stringkit` 的轻量级 Python 字符串处理工具包，提供三个核心纯字符串处理函数（`reverse`、`is_palindrome`、`count_vowels`），并附带完整的单元测试与用法说明文档，满足基础字符串操作需求。

### 1.2 目标用户

- **开发者**：需要在 Python 项目中使用基础字符串反转、回文判断、元音统计功能的开发人员。
- **学习者**：希望通过简洁示例了解 Python 函数定义、测试编写与文档组织的入门用户。

## 二、功能需求清单

| 编号 | 名称 | 描述 | 优先级 |
|------|------|------|--------|
| REQ-001 | `reverse(s)` | 接收字符串 `s`，返回反转后的字符串。传入非字符串类型时应抛出 `TypeError`。 | 必须 |
| REQ-002 | `is_palindrome(s)` | 接收字符串 `s`，忽略大小写与空格，判断是否为回文字符串，返回布尔值。 | 必须 |
| REQ-003 | `count_vowels(s)` | 接收字符串 `s`，统计其中元音字母（a、e、i、o、u，不区分大小写）的个数，返回整数。 | 必须 |
| REQ-004 | 单元测试 | 为上述三个函数提供覆盖基本场景与边界条件的单元测试，使用 `pytest` 框架执行。 | 必须 |
| REQ-005 | 用法说明 | 提供简要的 API 文档或使用示例（以 `README.md` 形式交付），说明各函数的调用方式。 | 应该 |

## 四、验收标准

### REQ-001：`reverse(s)`

- ✅ 通过条件：对任意字符串 `s`，`reverse(s)` 返回的反转字符串满足 `reverse(s) == s[::-1]`；传入 `None` 时抛出 `TypeError`。单元测试覆盖正常字符串、空字符串、`None` 等场景，全部断言成立。
- ❌ 不通过条件：存在任一断言失败。

### REQ-002：`is_palindrome(s)`

- ✅ 通过条件：对任意字符串 `s`，`is_palindrome(s)` 忽略大小写与空格后判断回文；例如 `is_palindrome("A man a plan a canal Panama")` 返回 `True`。单元测试覆盖含大小写、空格、标点符号等场景，结果正确。
- ❌ 不通过条件：对已知回文/非回文输入返回错误结果。

### REQ-003：`count_vowels(s)`

- ✅ 通过条件：对任意字符串 `s`，`count_vowels(s)` 正确统计英文元音字母个数（不区分大小写）。单元测试覆盖含元音、无元音、混合大小写等场景，计数正确。
- ❌ 不通过条件：存在任一断言失败。

### REQ-004：单元测试

- ✅ 通过条件：运行 `pytest` 后所有测试通过，覆盖率不低于 80%。
- ❌ 不通过条件：存在失败测试或覆盖率过低。

### REQ-005：用法说明

- ✅ 通过条件：用户文档包含各函数签名、简短说明及至少一个调用示例，文档可读且示例可直接运行得到正确结果。
- ❌ 不通过条件：缺失关键信息或示例无法执行。

## 五、假设与约束

- 函数参数均为字符串类型，若传入其他类型应抛出异常（如 `TypeError`）。  
  【假设】工具包应遵循 Python 类型错误处理惯例。

- "忽略大小写和空格"仅指在回文判断时去除空格、统一转为小写进行比较。  
  【假设】不需要处理其他空白字符（如制表符、换行符）的规范化。

- 元音字母仅包含 `a、e、i、o、u`（不区分大小写），不包含 `y`。  
  【假设】按英语常规定义统计。

- 单元测试框架使用 `pytest`。  
  【假设】基于 Python 社区常用测试工具。

- 项目仓库结构为扁平化包，无复杂目录嵌套。  
  【假设】未指定目录约束，仅按工具包常规组织。

## 六、范围外事项

以下事项明确不在本项目范围内：

| 类别 | 说明 |
|------|------|
| 性能基准测试 | 不要求覆盖百万字符级大规模字符串的性能测试（待确认问题第4条）。 |
| 详细 API 文档生成 | 不提供 Sphinx 等工具生成的完整 API 文档，仅以 `README.md` 形式交付（待确认问题第5条）。 |
| CI/CD 流水线 | 不提供 `pyproject.toml` 配置文件及持续集成流水线支持（待确认问题第6条）。 |
| 多类型支持 | `reverse(s)` 仅处理字符串类型，不支持字节序列或其他序列类型（待确认问题第1条）。 |
| Unicode 空白字符规范化 | `is_palindrome(s)` 的"忽略空格"仅去除普通空格，不处理制表符、换行符等其他 Unicode 空白字符（待确认问题第2条）。 |
| 带音标字符支持 | `count_vowels(s)` 仅统计 ASCII 元音字母，不支持带音标的拉丁字母（如 `á、è`）（待确认问题第3条）。 |
