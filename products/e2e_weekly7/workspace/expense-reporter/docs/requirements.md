## 一、项目概述

### 1.1 项目背景

行政部每月需人工核对员工提交的报销记录 CSV，包括校验金额合法性、重复报销检测、类别月度限额比对及汇总报表生成。现有流程费时且易错，亟需自动化工具替代。

### 1.2 项目目标

交付一个纯标准库实现的命令行工具 `expense_reporter`，自动完成 CSV 导入、记录校验、去重、限额比对与汇总报表输出，降低行政人员工作量并提升数据准确性。

### 1.3 目标用户

| 用户角色 | 使用场景 |
|----------|----------|
| 行政专员 | 批量导入报销记录 CSV，获取异常清单与汇总报表 |
| 财务复核人员 | 依据报表与异常清单进行人工复核 |

### 1.4 交付物

```

├── expense_reporter/       # 源码包

```

## 二、功能需求清单

### REQ-001（必须）CSV 读取与解析

**描述**：读取 UTF-8 编码（带或不带 BOM 均可）的报销记录 CSV，表头顺序固定为 `date`、`employee`、`category`、`amount`、`currency`、`note`；多余列忽略。必需列缺失或某行字段数不符时，将该行记入解析错误清单（含行号与原因），不中断其余行的处理。

**优先级**：必须

---

### REQ-002（必须）单条记录校验规则

**描述**：每条有效解析的记录依次校验五项规则：

| 序号 | 规则 | 说明 |
|------|------|------|
| 1 | amount > 0 | 金额必须为正数 |
| 2 | date 有效 | 不晚于当天，且不早于 `--max-age-days` 参数指定天数之前（默认 365） |
| 3 | category 合法 | 属于允许集合 {travel, meal, office, other} |
| 4 | note 非空 | 去空白后非空字符串 |
| 5 | currency = CNY | 币种必须为人民币 |

任何一条不满足即记入异常清单，注明行号、违反的规则与原始字段值；同一条记录命中多条规则时逐条列出。

**优先级**：必须

---

### REQ-003（必须）重复报销检测

**描述**：同一员工、同一类别、同一金额、同一日期的记录视为重复；同一批次内第二次及之后出现的行标记为「重复」，第一次出现保留为有效。**重复检测仅在 REQ-002 校验之后进行，且仅针对未被判定为异常的记录**。

**优先级**：必须

---

### REQ-004（必须）类别月度限额校验

**描述**：限额配置为 JSON 文件（键为类别名，值为该类别每月金额上限，单位元）。按员工×类别×月份聚合有效记录金额，超出上限的记录按时间顺序标记为「超限」，直至该员工该类别当月剩余额度用尽。未提供 `--config` 或配置中缺少某类别时，该部分不做限额校验，并在报告中注明「未设限」。

**优先级**：必须

---

### REQ-005（必须）Markdown 汇总报表

**描述**：输出人类可读的 Markdown 报表，包含：

1. **报表头**：统计口径说明、生成时间、输入文件名、总行数
2. **汇总维度**：按员工、按类别、按月份的有效金额合计与笔数
3. **明细附录**：解析错误清单、异常清单、重复清单、超限清单，均含行号
4. **金额格式**：一律为两位小数；无任何清单时显示「无」

**优先级**：必须

---

### REQ-006（应该）JSON 机器可读输出

**描述**：`--json` 参数指定输出路径时，写出 JSON 文件，含 `summary`（三维合计）、`anomalies`、`duplicates`、`over_limit`、`parse_errors` 五个键。所有金额以字符串表示（两位小数），禁止以浮点数表示。

**优先级**：应该

---

### REQ-007（必须）命令行接口

**描述**：调用形式如下：

```bash
python -m expense_reporter input.csv \
  --config limits.json \
  --report report.md \
  --json report.json \
  --max-age-days 365
```

`--config`、`--json`、`--max-age-days` 均可省略。

**退出码契约**：

| 退出码 | 含义 |
|--------|------|
| 0 | 正常完成且无任何异常记录 |
| 1 | 完成处理但存在解析错误、异常、重复或超限记录 |
| 2 | 输入错误（输入文件不存在、必需列缺失、参数非法） |

**优先级**：必须

---

### REQ-008（应该）处理性能

**描述**：10,000 行合法记录在 30 秒内完成全部校验、去重与报表输出。

**优先级**：应该

---

### REQ-009（必须）自动化测试

**描述**：测试覆盖每条校验规则的边界（金额 0 与负数、日期边界、类别外值、空 note）、重复链、跨月限额、坏行解析、三种退出码、金额 Decimal 精度（如 0.1+0.2 类累加误差不得出现）。测试全部离线运行，不依赖网络。

**优先级**：必须

---

### REQ-010（应该）使用文档

**描述**：README.md 说明输入 CSV 格式、限额配置示例、全部参数与退出码表，并附一个可复制运行的完整示例。

**优先级**：应该

## 六、范围外事项

以下事项明确不在本项目范围内：

1. **历史数据比对**：重复检测仅作用于同批次内记录，不跨批次、不比对历史文件（参见 A-02）。
2. **多币种支持**：仅支持 CNY，其他币种一律判定为异常（参见 REQ-002 规则 5）。
3. **网络请求**：工具不访问任何外部服务，限额配置需本地提供。
4. **图形界面**：本项目为纯命令行工具，不提供 GUI。
5. **数据库持久化**：不集成数据库，所有数据在内存中处理，输出至文件。
6. **用户认证**：无用户登录或权限控制机制。
