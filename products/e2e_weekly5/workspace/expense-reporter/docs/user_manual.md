

# 报销单校验与汇总工具 用户手册

## 1. 功能简介

`expense_reporter` 是一款纯 Python 标准库实现的命令行工具，用于自动校验员工提交的报销记录 CSV 文件，并完成重复检测、类别限额比对与汇总报表生成。

**主要功能：**
- 批量导入报销记录（UTF-8 CSV，支持 BOM）
- 自动校验金额、日期、类别、备注等字段合法性
- 检测同批次内重复报销
- 按月度限额配置比对超限记录
- 输出 Markdown 格式汇总报表（含明细清单）
- 可选输出 JSON 格式机器可读数据

**目标用户：**
- **行政专员**：批量导入报销记录，查看异常清单与汇总报表
- **财务复核人员**：依据报表与异常清单进行人工复核

## 2. 快速上手

### 2.1 环境要求

- Python 3.9 或更高版本
- 无需安装第三方依赖（仅使用标准库）

### 2.2 输入文件要求

**报销记录 CSV 格式：**

```csv
date,employee,category,amount,currency,note
2024-01-15,张三,travel,350.00,CNY,出差高铁票
2024-01-16,李四,meal,85.50,CNY,客户餐费
```

必需列（顺序固定）：
- `date`：日期，格式 YYYY-MM-DD
- `employee`：员工姓名
- `category`：类别，可选值：`travel`、`meal`、`office`、`other`
- `amount`：金额，两位小数
- `currency`：币种，固定为 `CNY`
- `note`：备注，非空

可包含多余列，工具会自动忽略。

**限额配置 JSON 格式（可选）：**

```json
{
  "travel": 5000.00,
  "meal": 2000.00,
  "office": 1000.00
}
```

键为类别名，值为该类别每月金额上限（元）。未配置的类别不做限额校验。

### 2.3 基本命令

```bash
python -m expense_reporter input.csv --report report.md
```

## 3. 命令行参数说明

| 参数 | 是否必需 | 说明 |
|------|----------|------|
| `input.csv` | 是 | 报销记录 CSV 文件路径 |
| `--config <file>` | 否 | 限额配置 JSON 文件路径 |
| `--report <file>` | 是 | 输出 Markdown 报表路径 |
| `--json <file>` | 否 | 输出 JSON 数据文件路径 |
| `--max-age-days <N>` | 否 | 允许的最早日期天数，默认 365 天 |

**示例命令：**

```bash
# 完整参数示例
python -m expense_reporter input.csv \
  --config limits.json \
  --report report.md \
  --json report.json \
  --max-age-days 365

# 省略可选参数
python -m expense_reporter input.csv --report report.md
```

## 4. 功能详解与操作示例

### 4.1 CSV 读取与解析

**功能说明：** 工具自动读取 UTF-8 编码（含或不带 BOM）的 CSV 文件，按必需列顺序解析。行格式错误或字段缺失的记录会进入「解析错误清单」，不影响其他行的处理。

**操作示例：**

```bash
python -m expense_reporter sample.csv --report report.md
```

运行后查看 `report.md`，在「解析错误清单」中可查看格式错误的行号与原因。

**示例输出（解析错误清单片段）：**

```markdown
### 解析错误清单

| 行号 | 错误原因 | 原始内容 |
|------|----------|----------|
| 3 | 字段数不匹配，期望6列实际5列 | 2024-01-17,王五,travel,200.00 |
| 5 | amount 格式错误 | 2024-01-19,赵六,meal,abc,CNY,午餐 |
```

### 4.2 记录校验

**校验规则：**

1. **金额 > 0**：金额必须为正数
2. **日期范围**：不晚于当天，不早于 `--max-age-days` 天前
3. **类别合法**：必须是 `travel`、`meal`、`office`、`other` 之一
4. **备注非空**：去除空白后不能为空字符串
5. **币种为 CNY**：currency 字段必须为 `CNY`

**违规记录会进入「异常清单」，标注行号与违反规则。**

**示例：**

```bash
python -m expense_reporter input.csv --report report.md
```

查看 `report.md` 中的「异常清单」：

```markdown
### 异常清单

| 行号 | 违反规则 | 原始字段值 |
|------|----------|------------|
| 4 | amount <= 0 | amount=0.00 |
| 6 | category 不在允许集合 | category=rent |
| 8 | note 为空 | note=   |
```

### 4.3 重复报销检测

**检测规则：** 同一员工 × 同一类别 × 同一金额 × 同一日期 → 判定为重复。同批次内首次出现保留，后续出现标记为「重复」。

**示例：**

假设有三行相同记录：
```csv
2024-01-15,张三,travel,350.00,CNY,出差票
2024-01-15,张三,travel,350.00,CNY,出差票
2024-01-15,张三,travel,350.00,CNY,出差票
```

运行工具后，第一行进入汇总，第二、三行进入「重复清单」：

```markdown
### 重复清单

| 行号 | 重复键 | 出现次数 |
|------|--------|----------|
| 2 | 张三×travel×350.00×2024-01-15 | 2 |
| 3 | 张三×travel×350.00×2024-01-15 | 3 |
```

### 4.4 类别月度限额校验

**校验规则：** 按「员工 × 类别 × 月份」聚合有效记录金额，超出限额的记录（按时间顺序）标记为「超限」。

**限额配置示例：**

```json
{
  "travel": 5000.00,
  "meal": 2000.00
}
```

**操作示例：**

```bash
python -m expense_reporter input.csv --config limits.json --report report.md
```

查看「超限清单」：

```markdown
### 超限清单

| 行号 | 员工 | 类别 | 月份 | 累计金额 | 限额 | 剩余额度 |
|------|------|------|------|----------|------|----------|
| 12 | 张三 | travel | 2024-01 | 5200.00 | 5000.00 | 0.00 |
```

**未配置限额时的处理：** 若未提供 `--config` 或配置中缺少某类别，报告中会注明「未设限」，该部分不做限额校验。

### 4.5 Markdown 汇总报表

**报表结构：**

```markdown
# 报销汇总报表

## 统计信息
- 生成时间：2024-01-20 10:30:00
- 输入文件：input.csv
- 总行数：100

## 汇总统计

### 按员工
| 员工 | 笔数 | 金额 |
|------|------|------|
| 张三 | 15 | 3500.00 |

### 按类别
| 类别 | 笔数 | 金额 |
|------|------|------|
| travel | 20 | 5000.00 |

### 按月份
| 月份 | 笔数 | 金额 |
|------|------|------|
| 2024-01 | 35 | 8000.00 |

## 明细清单

### 解析错误清单
无

### 异常清单
无

### 重复清单
无

### 超限清单
无
```

### 4.6 JSON 机器可读输出

**启用方式：** 添加 `--json` 参数指定输出路径。

```bash
python -m expense_reporter input.csv --report report.md --json report.json
```

**JSON 结构：**

```json
{
  "summary": {
    "by_employee": [
      {"employee": "张三", "count": 15, "amount": "3500.00"}
    ],
    "by_category": [
      {"category": "travel", "count": 20, "amount": "5000.00"}
    ],
    "by_month": [
      {"month": "2024-01", "count": 35, "amount": "8000.00"}
    ]
  },
  "anomalies": [],
  "duplicates": [],
  "over_limit": [],
  "parse_errors": []
}
```

**注意：** 所有金额字段均为字符串（两位小数），不使用浮点数。

## 5. 退出码说明

| 退出码 | 含义 | 说明 |
|--------|------|------|
| `0` | 正常完成 | 无解析错误、无异常、无重复、无超限 |
| `1` | 处理完成但有问题 | 存在解析错误、异常、重复或超限记录 |
| `2` | 输入错误 | 输入文件不存在、必需列缺失、参数非法 |

**示例：**

```bash
python -m expense_reporter input.csv --report report.md
echo $?  # 输出退出码
```

## 6. 常见问题 FAQ

### Q1：CSV 文件编码必须是什么？
**A：** 必须为 UTF-8 编码（带或不带 BOM 均可）。

### Q2：金额精度如何处理？
**A：** 内部使用 `Decimal` 类型计算，所有输出金额保留两位小数，避免浮点数精度误差。

### Q3：日期格式有什么要求？
**A：** 必须是 `YYYY-MM-DD` 格式，如 `2024-01-15`。

### Q4：可以校验历史月份的报销吗？
**A：** 可以。通过 `--max-age-days` 参数控制最早允许的日期。例如 `--max-age-days 730` 允许近两年内的报销。

### Q5：限额如何按月计算？
**A：** 限额按「员工 × 类别 × 月份」独立计算，跨月不累计。例如 1 月的 travel 限额与 2 月独立。

### Q6：重复报销如何定义？
**A：** 同一员工、同一类别、同一金额、同一日期的记录视为重复。仅限同一次导入批次内部比对，不与历史文件比对。

### Q7：未配置限额时会发生什么？
**A：** 若未提供 `--config` 参数或配置中缺少某类别，报告中会注明「未设限」，该类别不做限额校验。

### Q8：CSV 中有空行或格式错误的行会怎样？
**A：** 格式错误的行会进入「解析错误清单」，标注行号与错误原因，不影响其他行的处理。

### Q9：可以在 Windows 上使用吗？
**A：** 可以。工具仅使用 Python 标准库，兼容所有支持 Python 3.9+ 的平台。

### Q10：如何处理超过 10,000 行的文件？
**A：** 工具设计上支持大规模数据，但性能验证基于 10,000 行场景。超过此规模时建议分批处理。

## 7. 完整示例

### 场景：行政专员每月报销核对

**步骤 1：准备输入文件**

创建 `expenses.csv`：
```csv
date,employee,category,amount,currency,note
2024-01-05,张三,travel,1200.00,CNY,北京出差机票
2024-01-06,张三,meal,150.00,CNY,客户餐费
2024-01-06,张三,meal,150.00,CNY,客户餐费
2024-01-07,李四,office,300.00,CNY,办公用品
2024-01-10,王五,travel,4500.00,CNY,上海出差
```

创建 `limits.json`：
```json
{
  "travel": 5000.00,
  "meal": 2000.00
}
```

**步骤 2：运行工具**

```bash
python -m expense_reporter expenses.csv \
  --config limits.json \
  --report report.md \
  --json report.json
```

**步骤 3：查看结果**

打开 `report.md`，查看：
- 汇总统计（按员工、类别、月份）
- 重复清单（第 4 行与第 3 行重复）
- 超限清单（王五 1 月 travel 累计 4500，未超限）

打开 `report.json`，可查看机器可读数据供后续处理。

**步骤 4：检查退出码**

```bash
echo $?
# 输出 1（存在重复记录）
```
