## 一、项目概述

### 1.1 项目背景

行政部每月需人工核对员工报销 CSV 文件，包括查金额合法性、查重复报销、对照类别月度限额，再手工汇总成报表。该流程费时且易错，本项目旨在开发命令行工具实现自动化校验与汇总。

### 1.2 目标用户

| 角色 | 用途 |
|------|------|
| 行政专员 | 批量导入报销记录，得到异常清单与汇总报表 |
| 财务复核人员 | 依据报表与异常清单做人工复核 |

### 1.3 技术约束

- 仅使用 Python 标准库，不引入第三方依赖【来自需求规格草案原文约束】
- 金额计算一律使用 `Decimal`，禁止 `float` 聚合【来自需求规格草案原文约束】
- 不访问网络【来自需求规格草案原文约束】
- 输出信息面向行政人员，中文表述【来自需求规格草案原文约束】
- 输入编码：UTF-8（带或不带 BOM 均可）【来自需求规格草案原文约束】

### 1.4 范围外事项

| 编号 | 范围外事项 |
|------|------------|
| OOS-01 | 图形界面 |
| OOS-02 | 多币种支持 |
| OOS-03 | Excel 输入 |

| OOS-05 | 数据库持久化 |

## 二、功能需求清单

### REQ-001（必须）CSV 读取与解析

| 属性 | 说明 |
|------|------|
| **优先级** | 必须 |
| **描述** | 读取 UTF-8 编码（带或不带 BOM）的报销记录 CSV，必需列依次为：`date`、`employee`、`category`、`amount`、`currency`、`note`。缺少必需列或某行字段数不符时，将该行记入解析错误清单（含行号与原因），不中断其余行的处理。表头顺序固定，多余列忽略。 |
| **实现状态** | ✅ 已完成，测试通过 |
| **测试证据** | 18/18 测试通过，涵盖有效 CSV、缺少必需列、空文件、日期格式校验、金额格式校验、货币校验、混合行过滤、BOM 文件处理等场景 |

### REQ-002（必须）单条记录校验规则

| 属性 | 说明 |
|------|------|
| **优先级** | 必须 |
| **描述** | 每条有效解析的记录依次校验以下规则，任何一条不满足即记入异常清单，注明行号、违反的规则与原始字段值；同一条记录命中多条规则时逐条列出： |
| | 1. `amount` > 0； |
| | 2. `date` 不晚于当天，且不早于 `--max-age-days` 参数指定天数之前（默认 365）； |
| | 3. `category` 属于允许集合 {travel, meal, office, other}； |
| | 4. `note` 非空（去空白后）； |
| | 5. `currency` == "CNY"。 |
| **实现状态** | ⏳ 开发中（blocked） |
| **验收标准** | 构造覆盖每条规则的违规样例各至少一条，异常清单逐条命中且理由正确。 |

### REQ-003（必须）重复报销检测

| 属性 | 说明 |
|------|------|
| **优先级** | 必须 |
| **描述** | 同一员工、同一类别、同一金额、同一日期的记录视为重复；同一批次内第二次及之后出现的行标记为「重复」，第一次出现保留为有效。重复检测在校验之后进行，仅针对未被判定为异常的记录。 |
| **实现状态** | ⏳ 开发中（blocked） |
| **验收标准** | 构造三连同报销记录，输出中第一条约入汇总，后两条出现在重复清单。 |
| **假设** | 重复检测范围仅限同一次导入批次内部，不与历史文件比对【假设 A-01】 |

### REQ-004（必须）类别月度限额校验

| 属性 | 说明 |
|------|------|
| **优先级** | 必须 |
| **描述** | 限额配置为 JSON 文件，键为类别名，值为该类别每月金额上限（元）。按员工×类别×月份聚合有效记录金额，超出上限的记录按时间顺序标记为「超限」，直至该员工该类别当月剩余额度用尽。未提供 `--config` 或配置中缺少某类别时，该部分不做限额校验，并在报告中注明「未设限」。 |
| **实现状态** | ⏳ 开发中（blocked） |
| **验收标准** | 构造跨两月的样例与限额配置，超限标记与剩余额度计算完全正确；无配置运行时报告出现未设限说明。 |
| **假设** | 限额按「员工×类别×月份」独立计算，跨月不累计【假设 A-07】 |

### REQ-005（必须）Markdown 汇总报表

| 属性 | 说明 |
|------|------|
| **优先级** | 必须 |
| **描述** | 输出人类可读的 Markdown 报表，包含： |
| | 1. 报表头：统计口径说明、生成时间、输入文件名、总行数； |
| | 2. 三个汇总维度：按员工、按类别、按月份的有效金额合计与笔数； |
| | 3. 明细附录：解析错误清单、异常清单、重复清单、超限清单，均含行号； |
| | 4. 金额一律为两位小数。无任何清单时显示「无」。 |
| **实现状态** | ⏳ 开发中（blocked） |
| **验收标准** | 报表数字与手工核算一致；四个清单齐全；无任何清单时显示「无」。 |

### REQ-007（必须）命令行接口

| 属性 | 说明 |
|------|------|
| **优先级** | 必须 |
| **描述** | 调用形式为 `python -m expense_reporter input.csv --config limits.json --report report.md --json report.json --max-age-days 365`。`--config`、`--json`、`--max-age-days` 均可省略。退出码契约： |
| | - 0：正常完成且无任何异常记录； |
| | - 1：完成处理但存在解析错误、异常、重复或超限记录； |

| **实现状态** | ⏳ 开发中（blocked） |

| **假设** | 存在重复或超限但无异常与解析错误时，退出码同样为 1【假设 A-03】 |
