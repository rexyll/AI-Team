## 一、测试策略

### 1.1 测试范围

本次测试覆盖需求规格中的 REQ-001 至 REQ-010，重点验证：

- **REQ-001（CSV 读取与解析）**：UTF-8 BOM 支持、必需列校验、坏行容错处理
- **REQ-002（单条记录校验）**：金额正数、日期范围、类别白名单、note 非空、货币校验
- **REQ-003（重复报销检测）**：同员工×类别×金额×日期的去重逻辑
- **REQ-004（类别月度限额）**：按员工×类别×月份聚合、超限标记、剩余额度计算
- **REQ-005（Markdown 报表）**：统计口径、三维合计、四个清单附录
- **REQ-006（JSON 输出）**：结构完整性、金额字符串类型
- **REQ-007（命令行接口）**：参数解析、三种退出码语义
- **REQ-008（性能）**：10,000 行处理耗时 ≤ 30 秒
- **REQ-009（自动化测试）**：边界值、重复链、跨月限额、Decimal 精度
- **REQ-010（使用文档）**：格式说明、参数表、可运行示例

### 1.2 测试方法

| 方法 | 适用需求 | 说明 |
|------|----------|------|
| 单元测试 | REQ-001 ~ REQ-006 | 使用 pytest 对解析、校验、报表生成模块进行覆盖 |
| 集成测试 | REQ-007 | 验证命令行调用与退出码契约 |
| 性能测试 | REQ-008 | 生成 10,000 行合法 CSV 并计时 |
| 文档审查 | REQ-010 | 核对 README.md 内容完整性 |

### 1.3 测试限制

- 本项目仅使用 Python 标准库，不引入第三方测试框架外的依赖
- 所有测试离线运行，不访问网络
- 金额计算使用 `decimal.Decimal`，避免浮点误差
