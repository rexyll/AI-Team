

# stringkit 需求规格说明书

## 一、项目概述

### 1.1 项目名称
`stringkit`

### 1.2 项目背景
开发一个名为 `stringkit` 的 Python 工具包，提供三个字符串处理的纯函数，并附带单元测试和使用说明文档。该项目旨在为 Python 开发者提供一个轻量级、无依赖的字符串处理工具集合。

### 1.3 项目目标
- 实现 `reverse`、`is_palindrome`、`count_vowels` 三个核心字符串处理函数
- 确保函数为纯函数，不产生副作用
- 提供完整的单元测试覆盖
- 编写清晰的用法说明文档

## 二、目标用户

- **主要用户**：Python 开发者，需要在项目中使用字符串反转、回文判断、元音统计等基础功能
- **次要用户**：技术评审人员、代码审计人员

## 三、功能需求清单

| 编号 | 名称 | 描述 | 优先级 |
|------|------|------|--------|
| REQ-001 | reverse(s) | 接收字符串参数，返回反转后的字符串 | 必须 |
| REQ-002 | is_palindrome(s) | 接收字符串参数，忽略大小写和空格，判断是否为回文 | 必须 |
| REQ-003 | count_vowels(s) | 接收字符串参数，统计其中元音字母（a/e/i/o/u，不区分大小写）的个数 | 必须 |
| REQ-004 | 单元测试 | 为上述三个函数提供覆盖正常路径与边界情况的单元测试 | 应该 |
| REQ-005 | 简要用法说明 | 提供 README，包含安装方式、函数签名及调用示例 | 应该 |

### 3.1 功能需求说明

#### REQ-001 reverse(s)
接收一个字符串参数，返回字符顺序反转后的新字符串。函数应为纯函数，不修改输入参数。支持空字符串输入，空字符串反转后仍为空字符串。支持 Unicode 字符，按码点顺序反转。

#### REQ-002 is_palindrome(s)
接收一个字符串参数，忽略大小写和空格后判断是否为回文。空字符串视为回文（返回 `True`）。除空格外，其他字符（标点、数字）保留参与比较。

#### REQ-003 count_vowels(s)
接收一个字符串参数，统计其中元音字母（a/e/i/o/u）的个数，不区分大小写。不含 y/Y。空字符串返回 0。非字母字符不计入统计。

#### REQ-004 单元测试
使用 `pytest` 框架为三个核心函数编写单元测试，覆盖正常路径与边界情况。测试文件位于 `tests/` 目录下，命名符合框架规范。

#### REQ-005 简要用法说明
提供 `README.md` 文档，包含：
- 安装方式示例
- 三个函数的签名说明
- 调用示例代码

## 六、假设与约束

### 6.1 假设

1. 【假设】三个函数均定义为模块顶层导出，可通过 `from stringkit import reverse, is_palindrome, count_vowels` 导入。
2. 【假设】项目使用 `pytest` 作为单元测试框架。
3. 【假设】"元音字母"仅指英文字母 a/e/i/o/u，不含 y。
4. 【假设】项目结构为标准 Python 包结构（含 `pyproject.toml` 或 `setup.py`）。

### 6.2 约束

1. 【约束】三个函数必须为纯函数，不得修改输入参数。
2. 【约束】`is_palindrome` 的判断仅忽略大小写和空格，其他字符（标点、数字）保留参与比较。

## 七、范围外事项

以下内容不在本项目范围内：

- 不处理多语言元音字符（如法语、德语的特殊元音）
- 不提供批量字符串处理接口
- 不集成第三方字符串处理库
- 不发布至 PyPI 或其他仓库（发布流程待确认）
- 不提供类型注解的完整覆盖（PEP 484 兼容性问题待评估）
