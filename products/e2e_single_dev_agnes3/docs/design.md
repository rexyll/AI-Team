

# stringkit 设计文档

## 1. 文档概述

本文档描述 `stringkit` Python 工具包的总体架构、模块划分、关键接口与数据结构、目录结构及关键技术决策。`stringkit` 提供三个字符串处理纯函数（`reverse`、`is_palindrome`、`count_vowels`），附带完整的单元测试与用法说明文档。

## 3. 总体架构

### 3.1 架构选型

采用**扁平单模块结构**，将三个纯函数集中于单一实现文件，由包入口统一暴露 API。

```
stringkit/
├── __init__.py          # 模块入口，统一导出公开 API
├── stringops.py         # 三个核心纯函数实现
├── tests/
│   └── test_stringops.py  # 单元测试（34 个用例）
├── README.md            # 用法说明文档
└── pyproject.toml       # 项目元数据与依赖配置
```

**选型理由**：功能聚焦且函数数量仅三个，扁平结构降低维护成本，符合 KISS 原则，无需引入多模块分层开销。

## 5. 关键接口设计

### 5.1 `reverse(s: str) -> str`

| 属性 | 约定 |
|------|------|
| 参数 | 字符串类型（含空串 `""`）；非字符串输入（如 `None`、整数）抛出 `TypeError` |
| 返回 | 字符顺序反转后的新字符串，与原串等长 |
| 边界 | 空串返回空串；含非 ASCII 字符时按码点反转 |

**对应验收项**：A-01 ~ A-05

### 5.2 `is_palindrome(s: str) -> bool`

| 属性 | 约定 |
|------|------|
| 参数 | 任意字符串 |
| 返回 | 是否为回文（`True` / `False`） |
| 边界 | 空串视为回文（返回 `True`）；忽略大小写和空格；其他字符（标点、数字）保留参与比较 |

**对应验收项**：A-06 ~ A-10

### 5.3 `count_vowels(s: str) -> int`

| 属性 | 约定 |
|------|------|
| 参数 | 任意字符串 |
| 返回 | 元音字母数量（a/e/i/o/u，大小写均计入），非负整数 |
| 边界 | 不含 `y/Y`；空串返回 0；非字母字符忽略 |

**对应验收项**：A-11 ~ A-15

## 6. 数据结构

本模块不涉及复杂数据结构，三个函数均以原生 Python 类型进行交互：

| 字段 | 类型 | 约束 |
|------|------|------|
| 输入字符串 `s` | `str` | 支持 Unicode；允许空字符串 `""` |
| `reverse` 返回值 | `str` | 与原串等长 |
| `is_palindrome` 返回值 | `bool` | 仅返回 `True` / `False` |
| `count_vowels` 返回值 | `int` | ≥ 0 |

## 7. 关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 语言范围 | 英文元音（a, e, i, o, u） | 需求未提多语言支持，保守设计避免过度扩展 |
| `is_palindrome` 大小写处理 | 忽略大小写和空格 | 需求明确要求忽略大小写和空格；保留其他字符参与比较 |
| `count_vowels` 大小写处理 | 大小写均计入 | 需求明确"不区分大小写"统计元音 |
| 空串行为 | `reverse("") → ""`；`is_palindrome("") → True`；`count_vowels("") → 0` | 数学语义自然，符合验收标准 |
| 非字符串输入处理 | `reverse` 和 `count_vowels` 对非字符串输入抛出 `TypeError` | 满足 REQ-001 / REQ-003 验收项 A-05 |
| 模块文件命名 | 使用 `stringops.py`（而非设计阶段建议的 `core.py`） | 文件名更准确反映内容（字符串操作），不影响功能 |
