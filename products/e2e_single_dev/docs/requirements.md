## 一、项目背景

随着字符串处理任务的日常化，开发团队需要一套轻量级、零依赖的 Python 工具包，用于处理常见的字符串反转、回文判断与元音统计操作。`stringkit` 项目旨在提供三个纯函数，以标准 Python 包形式发布，便于集成到其他项目中，降低重复实现成本。

> 来源：项目规划摘要

### 功能需求详细说明

#### REQ-001 — reverse

**功能描述**：将输入字符串的字符顺序完全颠倒，返回新的字符串，不修改原字符串。

**函数签名**：
```python
def reverse(s: str) -> str
```

**前置条件**：输入 `s` 为 `str` 类型（见【约束-2】）。

**后置条件**：返回长度为 `len(s)` 的字符串，字符顺序与原字符串相反。

**实现报告**：已在 `stringkit/stringkit/stringkit.py` 中实现，逻辑符合上述契约。

> 来源：任务实现报告 [TASK-002]、架构设计 [TASK-001]

---

#### REQ-002 — is_palindrome

**功能描述**：判断输入字符串是否回文。判断过程中忽略大小写差异和空格，仅比较字母序列是否对称。

**函数签名**：
```python
def is_palindrome(s: str) -> bool
```

**处理规则**：
1. 将字符串转为小写
2. 移除所有空格
3. 比较处理后字符串与其反转是否相等

**实现报告**：已在 `stringkit/stringkit/stringkit.py` 中实现，处理规则与上述一致。

> 来源：任务实现报告 [TASK-002]、架构设计 [TASK-001]

**函数签名**：

**实现报告**：已在 `stringkit/stringkit/stringkit.py` 中实现。

## 五、验收标准

### REQ-001 reverse

- **通过**：调用 `reverse("abc")` 返回 `"cba"`；调用 `reverse("")` 返回 `""`
- **不通过**：对任意输入返回的内容与逐字符倒序结果不一致

### REQ-002 is_palindrome

- **通过**：`is_palindrome("A man a plan a canal Panama")` 返回 `True`；`is_palindrome("hello")` 返回 `False`；`is_palindrome("Madam")` 返回 `True`
- **不通过**：忽略大小写或空格后仍给出错误判断

### REQ-003 count_vowels

- **通过**：`count_vowels("hello")` 返回 `2`；`count_vowels("AEIOU")` 返回 `5`；`count_vowels("rhythm")` 返回 `0`
- **不通过**：元音统计数量与实际不符，或 y/Y 被错误计入/遗漏

### REQ-004 单元测试

- **通过**：存在测试文件，覆盖三个函数的正常输入与至少一种边界情况（如空字符串），所有用例执行结果为通过
- **不通过**：缺少任一函数的测试，或测试中有用例失败

### REQ-005 用法说明

- **通过**：存在可读的文档或 docstring，说明函数名称、参数与返回值
- **不通过**：无任何使用说明
