## 一、项目概述

### 1.1 项目背景

行政部每月需人工核对员工提交的报销记录 CSV，涉及金额合法性检查、重复报销检测、类别月度限额比对及手工汇总报表生成，效率低且易出错。本项目交付一个纯标准库实现的命令行工具，自动完成校验、去重、限额比对与汇总报表输出。

**来源**：需求规格草案「项目概述」节

### 1.2 目标用户

| 角色 | 用途 |
|------|------|
| 行政专员 | 批量导入报销 CSV，获取异常清单与汇总报表 |
| 财务复核人员 | 依据报表与异常清单进行人工复核 |

**来源**：需求规格草案「目标用户」节

### 1.3 交付物位置

`workspace/expense-reporter/`（含源码包、自动化测试与 README.md 使用文档）

**来源**：需求规格草案「交付物位置」节

### 1.4 技术约束

- 纯 Python 标准库，不引入第三方依赖
- 金额计算一律使用 `Decimal`，禁止 `float` 聚合
- 不访问网络，所有操作离线运行

**来源**：需求规格草案「技术约束」节

## 二、功能需求清单

### REQ-001【必须】CSV 读取与解析

**描述**：读取 UTF-8 编码（带或不带 BOM）的报销记录 CSV。必需列依次为 `date`、`employee`、`category`、`amount`、`currency`、`note`。`date` 格式为 YYYY-MM-DD，`amount` 为两位小数金额字符串，`currency` 固定为 CNY。缺少必需列或某行字段数不符时，将该行记入解析错误清单（含行号与原因），不中断其余行的处理。表头顺序固定，多余列忽略。

**优先级**：必须

**来源**：需求规格草案 REQ-001

**实现状态**：已实现，11 项单元测试全部通过（TASK-002）

---

### REQ-002【必须】单条记录校验规则

**描述**：每条有效解析的记录依次校验以下规则，任何一条不满足即记入异常清单，注明行号、违反的规则与原始字段值；同一条记录命中多条规则时逐条列出：

1. `amount` 大于 0；
2. `date` 不晚于当天，且不早于 `--max-age-days` 参数指定天数之前（默认 365）；
3. `category` 属于允许集合 `travel`、`meal`、`office`、`other`；
4. `note` 非空（去空白后）；
5. `currency` 为 CNY。

**优先级**：必须

**来源**：需求规格草案 REQ-002

**实现状态**：待实现

---

### REQ-003【必须】重复报销检测

**描述**：同一员工、同一类别、同一金额、同一日期的记录视为重复。同一批次内第二次及之后出现的行标记为「重复」，第一次出现保留为有效。重复检测在校验之后进行，仅针对未被判定为异常的记录。**重复检测范围仅限同一次导入批次内部，不与历史文件比对。**

**优先级**：必须

**来源**：需求规格草案 REQ-003

**实现状态**：待实现

---

### REQ-004【必须】类别月度限额校验

**描述**：限额配置为 JSON 文件，键为类别名，值为该类别每月金额上限（元）。按「员工×类别×月份」聚合有效记录金额，超出上限的记录按时间顺序标记为「超限」，直至该员工该类别当月剩余额度用尽。限额按「员工×类别×月份」独立计算，跨月不累计。未提供 `--config` 或配置中缺少某类别时，该部分不做限额校验，并在报告中注明「未设限」。

**优先级**：必须

**来源**：需求规格草案 REQ-004

**实现状态**：待实现

---

### REQ-005【必须】Markdown 汇总报表

**描述**：输出人类可读的 Markdown 报表，包含：

1. 报表头：统计口径说明、生成时间、输入文件名、总行数；
2. 三个汇总维度：按员工、按类别、按月份的有效金额合计与笔数；
3. 明细附录：解析错误清单、异常清单、重复清单、超限清单，均含行号；
4. 金额一律为两位小数。**无清单时显示「无」。**

**优先级**：必须

**来源**：需求规格草案 REQ-005

**实现状态**：待实现

**优先级**：应该

**来源**：需求规格草案 REQ-006

**实现状态**：待实现

### REQ-007【必须】命令行接口

**描述**：调用形式为：

```bash
python -m expense_reporter input.csv --config limits.json --report report.md --json report.json --max-age-days 365
```

`--config`、`--json`、`--max-age-days` 均可省略。退出码契约：

| 退出码 | 含义 |
|--------|------|
| `0` | 正常完成且无任何异常记录（含解析错误、异常、重复、超限） |
| `1` | 完成处理但存在解析错误、异常、重复或超限记录 |
| `2` | 输入错误（输入文件不存在、必需列缺失、参数非法） |

**优先级**：必须

**来源**：需求规格草案 REQ-007

**实现状态**：待实现
